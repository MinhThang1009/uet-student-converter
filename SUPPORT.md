# Support

UET Student Converter has a private GitHub repository but no public support
channel yet.

## Before requesting support

1. Read [README.md](README.md) and check paths under `data/input/`.
2. Run the checks listed in [CONTRIBUTING.md](CONTRIBUTING.md).
3. Remove student names, MSSVs, accounts, passwords, and personal data from
   every log or attachment.

## When publishing the repository

The maintainer should publish an issue template and provide a specific support
channel before opening the project to broader collaboration. Do not send
security issues through a public channel; see [SECURITY.md](SECURITY.md).
