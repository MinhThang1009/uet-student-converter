# Support

UET Student Converter is a public GitHub repository. For usage questions, bug
reports, or feature requests, open an issue using the [question form](.github/ISSUE_TEMPLATE/question.yml),
[bug report form](.github/ISSUE_TEMPLATE/bug_report.yml), or
[feature request form](.github/ISSUE_TEMPLATE/feature_request.yml).

## Before requesting support

1. Read [README.md](README.md) and check paths under `data/input/`.
2. Run the checks listed in [CONTRIBUTING.md](CONTRIBUTING.md).
3. Remove student names, MSSVs, accounts, passwords, and personal data from
   every log or attachment.

Do not attach real student data, credentials, or secrets to a public issue. Do
not report security vulnerabilities through public issues or pull requests; see
[SECURITY.md](SECURITY.md) for the current reporting limitations.
